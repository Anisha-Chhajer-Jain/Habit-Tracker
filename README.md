# Projects-HTML-CSS-JS 🚀

## 📌 Repository Overview

This repository contains a collection of **frontend web development projects** built using **HTML, CSS, and JavaScript**. These projects were created to practice and demonstrate different web development concepts such as user interfaces, interactivity, and simple application logic.

Each project focuses on solving a specific problem and improving practical skills in **UI design, DOM manipulation, and responsive layouts**.

---

## 🛠 Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **JavaScript** – Interactivity and dynamic functionality

---

## 📂 Projects Included

### 🤖 AI Bot

A simple chatbot interface that simulates conversation with users.

**Features**

* User message input
* Bot response display
* Chat interface layout

---

### 😊 Emotion Detector

A small project that detects or represents user emotions based on input.

**Features**

* Emotion-based responses
* Interactive UI
* Dynamic message display

---

### 📊 Habit Tracker

A web application that helps users track their daily habits and monitor progress.

**Features**

* Add daily habits
* Track completion
* Visual habit tracking interface

---

### 🎓 Student Dashboard

A dashboard interface designed to display student-related information.

**Features**

* Organized student data layout
* Dashboard style UI
* Sections for tasks, progress, or activities

---

### ✅ Todo List

A simple task management application that helps users manage their daily tasks.

**Features**

* Add tasks
* Mark tasks as completed
* Delete tasks
* Interactive task list
